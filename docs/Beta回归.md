## 3. 已知限制 / 未覆盖

- **4K / 多屏 / 混合 DPI / RDP / HDR / 独占全屏**：无硬件/环境，暂缓；已记录在 [待办](待办.md)。
- **设置页目录浏览对话框**：本轮未自动化点击系统文件夹选择器；保存路径输入与保存流程已验证。
- **托盘菜单交互**：托盘图标注册正常；菜单项本轮未重新自动化点击，沿用 beta.3 手工结果，代码未改动菜单协议。
- **长截图**：仅完成方案评估，未实现。
- **MSI 安装包 / 自动更新**：延后。
- 长时间挂机、热键冲突、异常恢复：本轮只做短时 soak，发布前再补长跑。
- 贴图保存固定为默认截图目录，不读取自定义保存目录（后续可调整）。
- 贴图不持久化，退出程序即消失。

## 4. 结论

自动化回归、便携包构建与主流程测试均通过，未发现阻塞性问题。UI kit 重构后遮罩、工具栏、贴图与设置页行为正常，可以进入 GitHub 发布准备（便携 zip 已生成，安装包随后）。
