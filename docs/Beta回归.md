- **4K / 多屏 / 混合 DPI / RDP / HDR / 独占全屏**：无硬件/环境，暂缓；已记录在 [待办](待办.md)。

- 贴图不持久化，退出程序即消失。

## 4. Beta 手工测试建议（供外部测试者）

1. 热键截取一块区域，确认遮罩、选区手柄光标、工具栏位置正常；
2. 依次用箭头、序号（连续点 12 次）、文字（长文本）、高亮、马赛克标注并保存；
3. 拖动/缩放文字框，确认导出按新宽度换行；
4. 悬停工具栏确认 tooltip；
5. 点击贴图，确认阴影、外侧按钮、Ctrl+滚轮百分比、Enter 保存、Ctrl+C 复制、Esc 关闭；
6. 重启程序，检查配置、上次选区、单实例转发；
7. 记录异常日志：`%LOCALAPPDATA%\window-cap\logs`。
