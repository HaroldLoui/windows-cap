# 已知问题

> 版本：0.10.0　更新：2026-11-04  
> 记录当前版本已确认的限制与未验证场景；新问题请到 <https://github.com/HaroldLoui/windows-cap/issues> 反馈。  
> 日志目录：`%LOCALAPPDATA%\window-cap\logs`（`app.log` / `app-warn.log` / `app-error.log`）。

## 未验证环境（可能有问题）

| 场景 | 影响 | 现状 |
|---|---|---|
| 4K（3840×2160） | 首帧/合成耗时、内存 | 未验证 |
| 多显示器 UI 交互 | 跨屏选区、工具栏放置、DPI 切换 | 仅验证整虚拟桌面采集（双屏 5120×1600） |
| 远程桌面（RDP） | 采集黑屏 | 未验证 |
| HDR 显示器 | 颜色偏亮/偏暗 | 未验证 |
| 独占全屏 / 游戏 | GDI 采集黑屏 | 部分窗口无法采集 |
| 高刷新率（144/240 Hz） | 拖动帧率 | 未验证 |

## 功能限制

- **截长图**：未实现，仅有方案（手动滚动 + 纵向拼接）。
- **安装包 / 自动更新**：只提供便携 zip，无 MSI、无自更新。
- **配置热重载**：修改 `config.toml` 后需从托盘菜单「重载配置」。
- **第二实例 `--capture`**：在本进程直接执行，不转发给已常驻实例（仅启动参数会转发）。
- **贴图**：不持久化，退出即消失；保存固定使用默认截图目录。
- **托盘图标**：Win11 可能收进溢出区，暂无引导/固定提示。
- **无 panic hook**：异常崩溃不写专门日志，需查看 `app.log` 末尾定位。
- **文字输入**：复杂 IME 组合（候选窗、多行）偶有焦点/光标异常。
- **长时挂机**：未做 24 h 常驻验证；本轮只跑 `--soak 200`。

## 采集相关

- 部分 DRM / 独占全屏窗口 GDI 采集为黑屏，无法通过配置规避。
- 虚拟桌面为矩形并集：显示器高度不一致时，较高显示器上方的空隙区域为纯黑，属正常现象。
