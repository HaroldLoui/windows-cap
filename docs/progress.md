## P3 交付清单

- `annotate/mod.rs`：`Document`（底图 + 成品表面 + 形状列表 + 撤销栈）、增量绘制、撤销/重做、导出 `Frame`
- `annotate/render.rs`：GDI+ 进程级初始化、`UnitPixel` + 抗锯齿、矢量形状、文字、序号、马赛克（块平均）
- `ui/toolbar.rs`：10 个工具 + 8 种颜色 + 线宽 ± + 撤销/重做/复制/保存/关闭；布局、命中、绘制
- `ui/text_edit.rs`：`EDIT` 子窗口 + 子类化；回车提交、Shift+回车换行、Esc 取消；独立 IME 上下文
- `ui/overlay.rs`：
  - **合成缓冲**：压暗背景 + 文档表面 + 实时预览 + chrome + 工具栏合成到一张全屏 DIB，单次 `BitBlt`（修复 K1 闪烁）
  - 工具交互：画笔/直线/箭头/矩形/椭圆/高亮/文字/马赛克/序号
  - 键盘：工具快捷键、`Ctrl+Z/Y`、方向键、`[`/`]` 线宽
  - 文字锚点与 IME；画完标注后锁定选区
- `app/hotkey.rs`：改为接收带标注的成品 `Frame`，直接复制/保存
- IME 兼容：遮罩禁用 IME（避免 `VK_PROCESSKEY` 吞掉快捷键），文字框单独创建 IME 上下文

## P3 修复记录（用户反馈）

| # | 反馈 | 修复 |
|---|---|---|
| F1 | 拖动选区时内容跟着边框一起走 | `Document` 记录 origin；移动/缩放过程中对冻结帧重新裁剪（同尺寸复用缓冲）；预览贴文档表面，内容固定于画面而非边框 |
| F2 | 文字输入框是白色不透明、字体颜色/大小像默认值 | 输入框去掉边框，`WM_CTLCOLOREDIT` 使用最终颜色 + 深色背景，字号与最终渲染一致（24px × DPI）；提交后仍用 GDI+ 栅格化 |
| F3 | 工具栏不好看 | 按用户要求暂不处理，功能正常 |

验证：

- 移动选区 `(200,200,600,450)` → `(300,230,600,450)` 后再画箭头，输出 600×450 且箭头坐标相对新选区正确（真实鼠标注入）；
- `Document::recrop` 单测：渐变画面移动后 surface 像素等于新位置裁剪；
- 文字粘贴「测试 Text 123」：输出文字区域 1926 个红色像素（字号已与最终一致）；
- 合成耗时回到 **3.6–5.2ms/帧**（1440p；AlphaBlend 方案实测 16.6ms，已改回预压暗位图）。
