## P2 交付清单

- `ui/selection.rs`：选区状态机（创建/移动/8 手柄缩放/方向键/边界 clamp），8 个单测
- `ui/overlay.rs`：全屏遮罩窗口
  - 冻结帧 + 预压暗位图 + 亮区还原
  - 选区边框、8 个手柄、`宽 × 高` 标签、操作提示
  - `Enter` / `Ctrl+C` / `Ctrl+S` / 双击确认；`Esc` / 右键 / 空白单击取消
  - `DwmSetWindowAttribute(DWMWA_TRANSITIONS_FORCEDISABLED)` 禁用淡入
  - 显示前记录前台窗口，结束后恢复
  - 脚本化选区（测试用）与首帧/绘制耗时日志
- `app/hotkey.rs`：
  - 常驻模式、`RegisterHotKey`、`Ctrl+Alt+A` / `Ctrl+Alt+Q`
  - 热键冲突时自动退避：`Ctrl+Alt+A` → `Ctrl+Shift+A` → `Ctrl+Alt+X`
  - 防重入（遮罩打开时忽略再次触发）
  - `--once`（单次流程）、`--overlay-selftest`（遮罩压力测试）
- `util/resources.rs`：GDI/USER 对象与工作集统计
- CLI：新增 `--hotkey`（默认）、`--once`、`--overlay-selftest`

## 偏差与说明

| 项 | 记录 |
|---|---|
| 热键冲突 | 测试机 `Ctrl+Alt+A` 曾被其他程序占用；实现自动退避并打印实际热键。P4 引入配置后由用户指定 |
| GDI 计数口径 | GDI/USER 子系统会懒分配，遮罩压力测试先预热 3 次再取基线 |
| 内存 soak 口径 | 每帧约 14.7 MB，分配器保留一块容量；`--soak` 预热 10 次后取基线，阈值 32 MB |
| 测试截图 | 端到端测试在 `%USERPROFILE%\Pictures\Screenshots` 生成了若干张 400×300 截图，可自行清理 |
| 退出码 | 后台任务显示 exit 1 是 PowerShell 把日志 stderr 当作错误；程序本身正常退出 |
| CLI 解析 | 仍为手写；P4 或收尾时切换 `clap`（已记录） |
| 第三方 crate | 允许引入；新增依赖需记录用途 |
