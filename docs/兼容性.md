## 自检命令

```powershell
window-cap.exe --selftest
window-cap.exe --overlay-selftest 50
window-cap.exe --soak 100
```

自检会输出：虚拟桌面、显示器数量、DPI、整屏采集耗时、区域截图一致性、剪贴板 CF_DIB、Unicode 路径落盘。

## 已知限制

- 单实例只覆盖常驻启动；`--capture` 始终在本进程执行（快速路径）。
- 第二实例转发只用于把启动参数交给已常驻实例。
- 便携版为 zip；MSI 安装包需 WiX，暂未提供。
