# 开发文档

本文帮助新开发者快速定位代码。功能索引按“用户看到的功能 → 代码位置”组织。

## 1. 项目概览

`window-cap` 是 Windows 截图/标注工具，Rust 2024 + `windows-rs`。

- 无 UI 采集：GDI `BitBlt` → 32 位 DIB
- 遮罩：全屏分层/合成窗口，冻结帧 + 选区 + 标注 + 工具栏
- 标注：GDI+ 矢量绘制，文档模型支持撤销/重做
- 输出：PNG 原子写入 + CF_DIB 剪贴板
- 常驻：托盘、全局热键、单实例、配置、开机自启
- 贴图：置顶分层窗口，阴影、拖动、缩放、复制/保存

技术栈：`windows = 0.62`、`image`、`serde`/`toml`、`clap`、`log`、`winresource`。

## 2. 目录结构

```
src/
  main.rs                 程序入口：日志、CLI、分发
  app/                    应用层：CLI、配置、常驻、托盘、单实例、自启
  capture/                屏幕采集与 Frame/RectI/VirtualScreen
  annotate/               标注数据模型与 GDI+ 渲染
  ui/                     遮罩、选区、工具栏、文字输入、贴图
  output/                 PNG 落盘、剪贴板
  platform/               DIB、测试图案窗口
  util/                   错误、日志、资源
  spike/                  技术验证代码（非主流程）
docs/                     进度、待办、兼容性、Beta 回归、本开发文档
scripts/                  打包脚本、工具栏 mockup
```

## 3. 启动与主流程

入口：[`src/main.rs`](../src/main.rs)

1. `util::log` 初始化日志（`%LOCALAPPDATA%\window-cap\logs`）。
2. [`app/cli.rs`](../src/app/cli.rs) 解析参数（clap）。
3. [`app/mod.rs`](../src/app/mod.rs) 按命令分发：
   - 默认 / `--hotkey`：常驻，进入 [`app/hotkey.rs`](../src/app/hotkey.rs)
   - `--once`：执行一次遮罩截图流程后退出
   - `--capture`：无 UI 采集
   - `--selftest` / `--overlay-selftest` / `--soak` / `--spike`：测试入口
   - `--autostart`：开机自启开关

常驻主循环（`hotkey.rs`）负责：注册全局热键、托盘窗口消息、单实例转发、延迟截图、配置重载。

## 4. 核心数据结构

| 类型 | 位置 | 说明 |
|---|---|---|
| `Frame` | `capture/mod.rs` | BGRA 像素 + 宽高 + 屏幕原点 |
| `RectI` / `VirtualScreen` | `capture/mod.rs` | 整数矩形、虚拟桌面范围 |
| `Shape` / `ShapeKind` / `Stroke` | `annotate/mod.rs` | 标注对象（线、箭头、矩形、文字、马赛克、序号等） |
| `Document` | `annotate/mod.rs` | 标注集合 + 撤销/重做 + 导出 |
| `SelectionState` | `ui/selection.rs` | 选区状态机（创建/移动/缩放） |
| `Toolbar` / `ToolbarState` | `ui/toolbar.rs` | 工具栏布局、按钮、绘制 |
| `OverlayResult` | `ui/overlay.rs` | 遮罩结果：Confirmed / Pinned / Cancelled |
| `Config` | `app/config.rs` | TOML 配置（capture/output/hotkey 等） |

坐标约定：屏幕坐标（物理像素）、遮罩客户区坐标、文档局部坐标。缩放/DPI 换算集中在遮罩与工具栏。

## 6. 关键流程

### 截图一次（常驻热键）

1. `hotkey.rs` 收到 `WM_HOTKEY`。
2. `capture_flow`：`GdiBackend` 抓整屏 → `ui::select` 打开遮罩。
3. 遮罩内：选区 → 标注 → 复制/保存/贴图。
4. 返回 `OverlayResult`；`apply_outputs` 负责剪贴板/PNG。
5. 记录上次选区，托盘/日志反馈。

### 遮罩绘制

- 冻结帧只解码一次；背景压暗成 `dim`。
- 有选区时，把选区原图、标注文档、预览、手柄、工具栏按序合成到 `composed` DIB，再一次 `BitBlt` 到窗口，避免闪烁。
- 鼠标移动立即重绘（事件驱动，不做固定帧率节流）。

### 贴图

- 遮罩点击“贴图” → `OverlayResult::Pinned` → `ui::pin::show`。
- 贴图是 `WS_EX_LAYERED | WS_EX_TOPMOST` 窗口，逐像素合成内容 + 阴影。
- 操作条是独立置顶小窗，位置随贴图拖动/缩放更新，关闭时一并销毁。

## 7. 构建、运行与发布

```powershell
cargo build --release
target\release\window-cap.exe            # 常驻
target\release\window-cap.exe --once     # 一次截图
cargo test
```

打包便携 zip：

```powershell
powershell -NoProfile -File scripts\package.ps1
```

产物在 `dist/`（已 gitignore）。

## 8. 代码与注释约定

- 注释用中文，文件顶部 `//!` 一句话说明职责。
- 函数/结构体 `///` 一句话说明“做什么”，细节留给代码。
- 长函数在关键阶段加 `// 步骤 1/2/3`，不逐行复述代码。
- 坐标必须写明是屏幕/客户区/文档坐标；资源释放顺序（GDI、DIB、GDI+）不要改动注释掉。
- 新工具：`Tool` → `TOOLS` → `ToolbarAction` → 遮罩鼠标处理 → `ShapeKind` → `render::draw_kind`。
- 新动作按钮：`ToolbarAction` → `Toolbar` 动作列表 → `overlay::apply_action` → `paint_pin_actions`（如需贴图操作条）。

## 9. 常见问题

- **release 启动时没有控制台**：使用 `windows_subsystem = "windows"`；CLI 输出见 `%LOCALAPPDATA%\window-cap\logs\cli.log`，调试构建仍输出到控制台。
- **热键无效**：检查 `config.toml` 的 hotkey、是否被其他程序占用；日志会记录注册失败。
- **采集黑屏**：部分独占全屏/DRM 窗口无法 GDI 采集；RDP/HDR 未验证。
- **DPI**：当前按每显示器 V2 DPI 感知；4K/混合 DPI 仍待硬件验证。
- **文字输入异常**：输入法是子窗口 EDIT + IME，检查焦点与 `close_text_editor` 调用。
- **贴图不显示**：只能从常驻模式（热键/托盘）进入；`--once` 不显示贴图按钮。
